# Roadmap

Ideas that fit Agent Orrery but aren't planned yet. Want one? Say so in an [issue](https://github.com/Luis-Sejer/agent-orrery/issues/new/choose), or build it: see [CONTRIBUTING.md](CONTRIBUTING.md).

- **A published Docker image.** Build and publish to the GitHub Container Registry on each release, so installing doesn't need a local build.
- **Other agents.** Codex and other coding agents that save transcripts locally.
- **Comets for events.** A short streak when something happens: from an agent to you when it starts waiting on you, outwards when it publishes an artifact, a red flare on a new Same-files collision. Only for new events, and rare enough to make you look.
- **Electrons for background shells.** A tiny electron circling a session's orb for each background command it's waiting on, gone when the command reports back.
