# Roadmap

Ideas that fit agent-graph but aren't planned yet. Want one? Say so in an [issue](https://github.com/Luis-Sejer/agent-graph/issues/new/choose), or build it: see [CONTRIBUTING.md](CONTRIBUTING.md).

- **A published Docker image.** Build and publish to the GitHub Container Registry on each release, so installing doesn't need a local build.
- **Notifications.** A browser notification when a session starts waiting on you, opt-in.
- **Watch instead of poll.** Use file system events instead of checking every second, for people with very many sessions.
- **Dark theme.** Following the system setting.
- **Search across transcripts' titles and plans at once.**
- **Other agents.** Codex and other coding agents that save transcripts locally.
